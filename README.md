# MineAI

MineAI is an AI-powered platform for [mining safety / risk monitoring / social-impact analytics] that combines a modern web UI with a scalable backend. It is built as a hackathon-style project to demonstrate how AI, computer vision, and data analytics can improve safety and decision-making in mining and related domains.
